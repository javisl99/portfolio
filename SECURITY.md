# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues or pull requests.

Use GitHub's private vulnerability reporting from the repository's **Security** tab when it is available. Include the affected path, the impact, reproduction steps, and any suggested mitigation. If private reporting is unavailable, contact the repository owner through their GitHub profile and avoid disclosing exploitable details publicly.

## Supported versions

The `main` branch is the supported version of this portfolio.
