## Problem

This was my first real step into enterprise software delivery. The challenge was not broad ownership yet, but learning quickly and contributing meaningfully inside a serious B2B environment for Airbus from the beginning.

It also pushed me to combine SAP ABAP and SAP Commerce Cloud work, building the kind of backend foundation and enterprise architecture exposure that later supported broader responsibilities.

## Solution

- Contributed to backend work on a B2B project for Airbus inside the SAP ecosystem.
- Built early familiarity with SAP Commerce Cloud as part of a professional delivery context rather than a training environment.
- Worked on SAP/ABAP implementation and maintenance tasks, including custom transactions, function modules, ALVs, dynpros, and enhancements.
- Supported technical maintenance, issue resolution, and feature delivery in a structured enterprise environment, strengthening my backend and enterprise architecture foundations.

## Tech stack

Java, Spring, SAP Commerce Cloud, SAP ABAP, and B2B enterprise delivery practices.

## Impact

This project gave me the technical and professional base from which the rest of my backend and enterprise-platform growth developed. It shows that my profile started from real engineering work in demanding enterprise contexts, not only from later production support or platform specialization.
