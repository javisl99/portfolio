## Context

At Accenture I started my professional career inside the Airbus project. It was my first real contact with SAP Commerce Cloud and SAP ABAP, in an environment where a B2B site was being built from scratch.

That starting point matters because it explains where my technical base inside the SAP ecosystem comes from.

## Role and responsibility

I contributed as a back-end developer during the project build. Because it was a greenfield environment, the experience was especially useful for understanding how a SAP Commerce solution is structured from the ground up and how technical work fits into a B2B product.

More than a stage of broad ownership, this was a stage of building core technical foundations inside a demanding environment.

## SAP technical focus

The strongest technical signals here are:

- back-end development on SAP Commerce Cloud,
- early exposure to SAP ABAP,
- and participation in a greenfield B2B project.

That gave me an initial understanding of the platform not only from issue resolution, but also from initial construction.

## Decisions and technical learning

### Learning inside a real project

The best part of this stage is that the learning did not come from an isolated sandbox, but from a real project with clear technical and functional expectations.

### A back-end base to grow from later

This experience gave me the starting point to understand structures, responsibilities, and delivery habits that I later deepened in more mature projects.

### Early exposure to the SAP ecosystem

Getting initial exposure to SAP Commerce Cloud and SAP ABAP in the same environment gave me a useful framework for understanding the SAP ecosystem from the start of my career.

## Professional impact

This case does not yet represent my stage of highest autonomy, but it explains the base on which I later grew: back-end development, B2B project work, fast learning, and a real entry point into the SAP Commerce ecosystem.
