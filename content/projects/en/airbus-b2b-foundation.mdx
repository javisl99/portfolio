## Context

This was my first real step into software delivery in a serious B2B environment. The context combined SAP/ABAP work and early SAP Commerce Cloud exposure inside a project being built from scratch.

It mattered because the technical base I built here later supported broader backend responsibilities around incidents, integrations, and production-facing work.

## Problem

The main challenge was learning fast enough to contribute in a demanding environment while understanding business processes and technology at the same time.

- Contributed to backend work on a B2B project for Airbus inside the SAP ecosystem.
- Built early familiarity with SAP Commerce Cloud in a professional delivery context.
- Worked on SAP/ABAP implementation and maintenance tasks, including function modules, ALVs, dynpros, custom transactions, and enhancements.
- Supported technical maintenance, issue resolution, and feature delivery in a structured environment.

## Technical stack

Java, Spring, SAP Commerce Cloud, SAP ABAP, B2B commerce, ALV, dynpros, and technical maintenance work.

## Impact

This project gave me the technical and professional base from which my later backend and business-platform responsibilities grew.

It shows real backend foundations, the ability to learn quickly, and an early entry into environments where business processes and technology are tightly connected.
