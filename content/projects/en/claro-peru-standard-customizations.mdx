## Context

Claro Perú was a B2B SAP Commerce Cloud project where checkout, pricing, stock, and integrations had direct weight on how the product operated.

That made every backend customization an important decision, because poor changes in those areas could affect functional behavior and make future evolution harder.

## Problem

The challenge was to deliver backend changes in sensitive flows without overengineering the solution or breaking expected SAP Commerce Cloud standard behavior.

## What I did

- Contributed to backend implementation on a SAP Commerce Cloud platform for Claro Perú.
- Developed changes tied to checkout, pricing, stock management, REST APIs, and integration behavior.
- Worked on sensitive functional behavior, learning better when to extend the standard and when to respect it.
- Deepened my understanding of data modelling and of how commerce flows depend on baseline platform mechanics.
- Used AI selectively to accelerate technical analysis and preparation work without delegating the technical decision itself.

## Technical stack

Java, Spring, SAP Commerce Cloud, Integration Objects, FlexibleSearch, SQL, checkout, pricing, stock, and integrations.

## Impact

This project strengthened my ability to work on business-sensitive backend flows with more technical rigor and better platform judgment.

## What this shows about my profile

It shows that I can work safely in delicate business areas, understand the technical implications of the platform standard, and deliver useful backend work without adding unnecessary complexity.
