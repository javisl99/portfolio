## Problem

Checkout, pricing, stock, and integrations are not peripheral concerns in an e-commerce platform. They are areas where low-quality customizations can create functional issues, technical debt, and long-term maintenance pain.

The challenge was to move faster without compromising maintainability, while also developing stronger judgment on when to extend the standard and when to respect it.

## Solution

- Contributed to backend implementation on a SAP Commerce Cloud platform for Claro Peru.
- Developed changes tied to checkout, pricing, stock management, and integration behavior.
- Integrated selective AI support to accelerate technical analysis and customization work around sensitive flows.
- Deepened my understanding of data modelling and of how enterprise e-commerce flows depend on standard platform mechanics.
- Built stronger judgment around extending the standard carefully instead of over-customizing core behavior.

## Tech stack

Java, Spring, SAP Commerce Cloud, Integration Objects, FlexibleSearch, SQL, and enterprise e-commerce flows.

## Impact

This project sharpened my ability to work on business-sensitive backend flows with more technical rigor and better platform judgment. It reinforced SAP Commerce Cloud as a strong specialization within a broader backend engineering trajectory built on Java and Spring.
