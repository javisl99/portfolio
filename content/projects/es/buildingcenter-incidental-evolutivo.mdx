## Problema

BuildingCenter no era un entorno controlado de desarrollo. Era una plataforma SAP Commerce Cloud viva, con presion operativa real, flujos sensibles para negocio y visibilidad directa desde cliente.

Eso significaba que cada cambio debia equilibrar velocidad de entrega, estabilidad de plataforma y comprension clara del impacto funcional.

## Solucion

- Desarrolle funcionalidad backend con Java, Spring y SAP Commerce Cloud sobre una plataforma ya activa en produccion.
- Trabaje sobre servicios, modelos de datos, jobs, interceptors, validators, integraciones y logica de negocio ligada al comportamiento core del sistema.
- Investigue incidencias, trace causas raiz y participe en mejoras de estabilidad en lugar de tratar los tickets como casos aislados.
- Colabore directamente con negocio, QA y equipos funcionales para transformar requisitos e incidencias en acciones tecnicas escalables.
- Use flujos AI-assisted para acelerar analisis tecnico, debugging, documentacion y tareas de ingenieria repetitivas.

## Tech stack

Java, Spring, SAP Commerce Cloud, SQL, FlexibleSearch, integraciones enterprise, analisis de incidencias y flujos de AI-Assisted Development.

## Impacto

Este caso refleja mejor que ningun otro mi posicionamiento actual como Backend Software Engineer: alguien capaz de entregar funcionalidad, sostener produccion, investigar problemas complejos y comunicarse con soltura entre capas tecnicas y de negocio dentro de una plataforma enterprise.
