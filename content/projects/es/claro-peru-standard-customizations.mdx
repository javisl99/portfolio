## Problema

Checkout, pricing, stock e integraciones no son detalles secundarios en una plataforma e-commerce. Son zonas donde una customizacion pobre puede generar problemas funcionales, deuda tecnica y coste de mantenimiento a largo plazo.

## Solucion

- Participe en implementacion backend sobre una plataforma SAP Commerce Cloud para Claro Peru.
- Desarrolle cambios relacionados con checkout, pricing, stock management y comportamiento de integraciones.
- Profundice en data modelling y en como los flujos enterprise de e-commerce dependen del funcionamiento base de la plataforma.
- Gane mas criterio para extender el estandar con cuidado en lugar de sobredimensionar customizaciones sobre comportamiento core.

## Tech stack

Java, Spring, SAP Commerce Cloud, Integration Objects, FlexibleSearch, SQL y flujos enterprise de e-commerce.

## Impacto

Este proyecto reforzo mi capacidad para trabajar sobre flujos backend sensibles con mas rigor tecnico y mejor criterio de plataforma. Consolidó SAP Commerce Cloud como una especializacion fuerte dentro de una trayectoria mas amplia en backend engineering.
