## Problema

Checkout, pricing, stock e integraciones no son detalles secundarios en una plataforma e-commerce. Son zonas donde una customización pobre puede generar problemas funcionales, deuda técnica y coste de mantenimiento a largo plazo.

El reto estaba en acelerar entrega sin comprometer mantenibilidad, ganando además mejor criterio para decidir cuándo extender el estándar y cuándo respetarlo.

## Solución

- Participé en implementación backend sobre una plataforma SAP Commerce Cloud para Claro Perú.
- Desarrollé cambios relacionados con checkout, pricing, stock management y comportamiento de integraciones.
- Integré apoyo puntual de IA para acelerar análisis técnico y preparación de cambios sobre flujos sensibles.
- Profundicé en data modelling y en cómo los flujos enterprise de e-commerce dependen del funcionamiento base de la plataforma.
- Gané más criterio para extender el estándar con cuidado en lugar de sobredimensionar customizaciones sobre comportamiento core.

## Tech stack

Java, Spring, SAP Commerce Cloud, Integration Objects, FlexibleSearch, SQL y flujos enterprise de e-commerce.

## Impacto

Este proyecto reforzó mi capacidad para trabajar sobre flujos backend sensibles con más rigor técnico y mejor criterio de plataforma. Consolidó SAP Commerce Cloud como una especialización fuerte dentro de una trayectoria más amplia en backend engineering, Java y Spring.
