## Contexto

Este fue mi primer paso real en entrega de software para un entorno B2B serio. El contexto combinaba trabajo SAP/ABAP y una primera exposición a SAP Commerce Cloud dentro de un proyecto que se estaba construyendo desde cero.

Fue una etapa importante porque la base técnica que construí aquí explicó después mi evolución hacia tareas más complejas de backend, incidencias e integraciones.

## Problema

El reto principal era aprender con la velocidad suficiente como para aportar en un entorno exigente, entendiendo procesos de negocio y tecnología al mismo tiempo.

## Qué hice

- Participé en trabajo backend sobre un proyecto B2B para Airbus dentro del ecosistema SAP.
- Gané familiaridad temprana con SAP Commerce Cloud dentro de un contexto profesional de entrega.
- Trabajé en implementación y mantenimiento SAP/ABAP, incluyendo function modules, ALVs, dynpros, transacciones personalizadas y enhancements.
- Apoyé mantenimiento técnico, resolución de incidencias y entrega de funcionalidad en un entorno estructurado.

## Stack técnico

Java, Spring, SAP Commerce Cloud, SAP ABAP, B2B commerce, ALV, dynpros y trabajo de mantenimiento técnico.

## Impacto

Este proyecto me dio la base técnica y profesional desde la que luego crecieron mis responsabilidades en backend y plataformas de negocio.

## Qué demuestra sobre mi perfil

Demuestra una base backend real, capacidad para aprender rápido y una entrada temprana a entornos donde negocio, procesos y tecnología van unidos.
